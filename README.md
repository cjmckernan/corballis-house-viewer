# Corballis house viewer

Interactive floor plans and furnished 3D views of Maple, Hazel, Poplar, Rowan, Sycamore, Ash and Hawthorn.

Open: https://cjmckernan.github.io/corballis-house-viewer/

- Maple uses an unconfirmed E1 planning analogue; 77 m² sales and 78 m² planning totals remain distinct.
- Hazel / E1.1 and Poplar / D1.1 are candidate matches, not confirmed sales or plot mappings.
- Rowan follows the brochure layout; all dimensions and room areas are estimates.
- Sycamore follows the 102 m² brochure courtyard/garage/terrace layout; exact room dimensions and a matching planning drawing remain unverified. All geometry is estimated.
- Ash (123 m²) and Hawthorn (118 m²) follow their separate brochure layouts. Room dimensions and matching planning codes remain unverified; geometry is estimated.
- Furniture and unverified construction geometry are illustrative. Check final contract drawings.

This repository contains only the privacy-cleaned static release. Application source, local source history, private plot details and server deployment configuration are excluded. GitHub Pages publishes the main branch with Jekyll disabled.
